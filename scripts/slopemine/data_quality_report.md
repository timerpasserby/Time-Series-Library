## 6. 位移-降雨重叠分析

| 指标 | 数值 |
|---|---|
| 位移阈值（mean+2std） | 0.724 |
| 降雨小时数 | 120 |
| 位移尖峰小时数 | 570 |
| 重叠小时数 | 92 |
| P(spike \| rain) | 76.7% |
| P(rain \| spike) | 16.1% |

**关键发现**：
- 降雨发生时，76.7% 的概率伴随位移尖峰，说明降雨确实能触发位移事件。
- 但位移尖峰中只有 16.1% 与降雨重叠，说明大多数位移事件由其他因素驱动（可能包括爆破、自然蠕变等）。
- 这进一步支持了"多源信息融合"的设计思路。

## 后续行动建议

1. **区域不平衡**：Zone 1 仅 32 点，后续分 patch 时需特别处理
2. **位移偏态**：训练时可能需要对位移做 log 变换或使用针对偏态设计的损失函数
3. **零值过多**：53.85% 零值可能影响模型训练，考虑是否需要特殊处理
4. **爆破数据**：降雨只解释了 16.1% 的位移尖峰，爆破数据的补充将非常重要
